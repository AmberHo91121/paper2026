研究架構 Research Framework · Stage C

酷兒女性經期追蹤實踐中的關係展演性：延伸 Chen (2026) 的框架

對應的研究缺口（替代來源：Chen 2026 論文自陳限制，見 02_研究架構_StageA.md）

Chen (2026) 的「親密資料展演性」框架建立在 16 位異性戀、未婚、無子女的順性別女性樣本上，作者明確排除酷兒群體、已為人母者，並建議未來研究延伸至其他脈絡比較。目前沒有研究檢視這個框架——尤其其中的「關係展演性」維度——是否適用於酷兒女性的經期追蹤實踐。

1 Problem / Aim / Objectives（Stage B 已確認，已依 Stage A 評判調整範圍）

Stage A 評判時發現 Aim 講「框架整體」但 Objectives 只深入處理「關係展演性」一個維度——已依建議把 Problem／Aim 的措辭都縮小到明確只聚焦這個維度，不再含糊指涉整個框架。

Problem

Chen (2026) 提出的「親密資料展演性」框架中的關係展演性維度，在酷兒女性的經期追蹤與親密關係實踐中是否仍然成立？

Aim

探討台灣酷兒女性使用經期追蹤 App 時的資料分享與關係協商實踐，檢視親密資料展演性框架中「關係展演性」這個維度，在非異性戀關係脈絡下是否需要修正。

Objectives

  • 描述酷兒女性在經期追蹤 App 使用上與 Chen (2026) 異性戀樣本的異同
  • 檢視「關係展演性」維度（照顧/監控的性別化動態）在同性伴侶脈絡下如何被重新詮釋
  • 根據酷兒女性的實踐經驗，提出「關係展演性」維度的修正或擴展

2 研究框架構念（Stage C）

理論構念

Relational Performativity（關係展演性，延續自 Chen 2026）、Queer Relationality（酷兒親密關係常規）、Surveillance Symmetry（監控對稱性，新構念）

原因：
Chen (2026) 的關係展演性預設異性戀伴侶的不對稱動態（男性伴侶追蹤女性）；要檢驗這個維度在酷兒脈絡下是否成立，需要一個能捕捉「對稱性」變化的構念，不能直接套用原本假設
限制：
「監控對稱性」目前沒有既有的量測工具或成熟定義，是探索性構念，資料蒐集後可能需要調整定義
影響：
訪談大綱需要特別設計能誘出「雙方追蹤動態」的問題，不能只從單一受訪者視角問

方法選擇

質化方法（半結構深度訪談，可能需考慮伴侶雙方訪談／dyadic 訪談）

原因：
延伸並檢驗既有質化理論框架，需保留跟 Chen (2026) 的方法論可比較性；關係展演性本質上是雙方協商的動態，適合開放式深度訪談，不適合量化測量
限制：
質化方法的發現不能推論到所有酷兒女性；只訪談一方看不到雙方視角的落差
影響：
Agent 4 規劃招募時要考慮是否要求成對招募（伴侶雙方都訪談），這會讓招募門檻提高，也牽涉到「單獨訪談單方」跟「訪談雙方」在倫理程序上的差異（要不要讓對方知道另一半也被訪談）

資料蒐集規劃（概要）

深度訪談若干位自認為酷兒（女同志/雙性戀等）、使用經期追蹤 App 的受訪者，理想上涵蓋不同關係狀態（單身／穩定伴侶關係），若可行考慮伴侶雙方都訪談（細節留給 Agent 4 研究設計）

原因：
樣本需同時滿足「酷兒認同」＋「經期追蹤 App 使用者」＋「願意談論親密關係」三個條件的交集，這個母體本身就小，規劃時要先預期招募比 Chen (2026) 的異性戀樣本更困難
限制：
這個交集母體小，樣本數可能明顯少於 Chen (2026) 的 16 人，結論的代表性要更保守地宣告
影響：
Agent 4 的招募條件要考慮透過酷兒社群管道（而非泛用平台）招募，時程要抓更長；且招募文宣措辭要避免意外揭露受訪者身份

分析方法（概要）

沿用 Agent 5（洞見萃取）的九層框架做主題分析，並在 04_對應研究框架.md 對照本次三個構念

原因：
跟 Chen (2026) 的分析取向一致（thematic analysis），方便未來直接比較；九層框架本身已是這條工作流程既有的標準做法
限制：
主題分析受研究者詮釋影響，Why/Insight/Implication 層級的判斷仍需人工覆核，不是機械式輸出
影響：
洞見萃取階段要特別留意「監控對稱性」這個探索性構念浮現的資料——它沒有既有理論可直接對照，Pattern 判定會更依賴資料本身，門檻判斷要更謹慎

預期貢獻

修正或擴展 Chen (2026) 的「親密資料展演性」框架，特別是「關係展演性」維度，使其能涵蓋非異性戀伴侶關係動態，回應酷兒群體研究缺口，對女性主義科技研究、酷兒理論與健康傳播三個領域都有貢獻。

3 對照參考

Chen (2026) — Intimate Data Performativity，關係展演性維度

原始定義建立在異性戀伴侶的不對稱追蹤動態上（男性伴侶追蹤女性經期，構成「surveillance-intimacy paradox」——關懷與監控交織）。本研究把這個定義當作基準線，檢驗同性伴侶脈絡下追蹤角色是否還維持這種不對稱、還是變得更對稱／協商式，藉此判斷這個維度需不需要修正。
