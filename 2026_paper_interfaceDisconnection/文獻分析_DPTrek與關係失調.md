## 1. Ye et al. (2025) — 從覺察到行動：體驗式學習對黑暗模式教育的效果（DPTrek）

**檔案**：`3706598.3713493.pdf`｜CHI '25, Yokohama｜作者：Jingzhou Ye, Yao Li, Wenting Zou, Xueqiang Wang

| 項目 | 內容 |
|---|---|
| 摘要 | 黑暗模式（dark patterns, DPs）是欺騙使用者做出非預期決定的不道德介面設計。既有研究多在定義分類與評估影響，法規與技術上的緩解有限，使用者仍暴露於風險，卻少有針對 DP 覺察的教育介入。研究提出 DPTrek——以模擬真實 DP 案例進行體驗式學習（experiential learning, EL）的平台。 |
| 背景 | DP 具心理操弄、缺乏透明、誤導與流程複雜等特性，傳統以事實為主的教學可能難以傳達其操弄本質，也難促使學習者重視潛在傷害。 |
| 問題 | 以體驗式學習教育使用者，能否比靜態網頁內容學習更有效地提升辨識與因應 DP 的能力？ |
| 方法 | 招募 38 位參與者做對照實驗：實驗組透過 DPTrek 學習，對照組透過網頁靜態內容學習；學習後進行 DP 因應測驗、DP 知識測驗、主觀評價問卷與結束訪談。統計以 Mann-Whitney U（組間）與 Wilcoxon 符號等級檢定（實驗組前後）；訪談用主題分析；測驗中涉及密碼／電話等敏感輸入者為自願且不記錄。 |
| 結果 | 實驗組的 DP 因應測驗總體與各 DP 類別準確率皆顯著高於對照組（p < 0.05）；知識測驗總體準確率兩組無顯著差異，但實驗組在對 DP 後果的理解上表現較佳；實驗組在 DPTrek 內，從「體驗」階段到「實驗」階段與最終因應測驗，準確率顯著提升（實驗與最終測驗之間無顯著差異）。訪談中參與者認為 DPTrek 有趣、美觀，並肯定真實案例。 |
| 討論 | 體驗式學習有助於發展處理 DP 的實作能力。負面回饋包括：因應策略（離開或檢舉網站）在使用者仍需使用該網站時不切實際、DP 分類不易辨識；作者指出「對使用者不友善的分類法」與「缺乏實務可行的緩解方案」為未來 DP 教育與研究的挑戰。 |

**對「介面斷裂」主題的用途（推論）**：方法論參考——pre/post 與對照組設計、以「辨識→因應」分階段測量學習成效；不宜當作 AI 生成物件持續使用率的實證證據（兩者現象不同）。

## 2. CHI '26 — 人機互動中的關係失調：知識工作案例（Relational Dissonance）

**檔案**：`3772318.3791180.pdf`｜CHI '26, Barcelona｜CC BY-NC-ND｜（作者列表請以 PDF 首頁為準，本檔未逐一核對）

| 項目 | 內容 |
|---|---|
| 摘要 | 擬人化對話式 AI 引發越來越複雜的關係性反應。知識工作者把這些系統當工具，互動時卻呈現類似人際的社會互動。透過 3 場、與質性研究者合辦的工作坊，發現此類代理在本體論與關係上的模糊，使人難以對其維持一致的關係立場；人們「口頭說明的定位」常與「互動當下實際發生的關係動態」不同。作者提出「關係失調（relational dissonance）」概念，並呼籲「關係透明（relational transparency）」。 |
| 背景 | 既有 HCI 框架不足以說明人與擬人化對話代理之間的關係脈絡；相關研究多以「AI 本體」為切入。 |
| 問題 | 知識工作者與擬人化對話代理互動時，會出現什麼關係脈絡？其外顯的關係定位與實際互動動態之間有何落差？ |
| 方法 | 2025 年 3–5 月共 3 場工作坊，22 位背景多元的質性研究者（使用經驗從初次使用到熟練提示工程皆有）；流程分三階段，由個人互動走向集體活動，含事前問卷；分析架構分「個人」與「社會」兩個維度。 |
| 結果 | 三個發現軸線：AI 系統介於「工具」與「他者」之間；關係配置在互動中擺盪；集體意義建構中出現對關係的共同詮釋。 |
| 討論 | 關係失調＝個人對 AI 的本體論／關係框架，與互動展開時浮現的關係動態之間的分歧，源於難以穩定回答「AI 是什麼」與「AI 對我而言是什麼」；其外顯層與內隱層的落差常在互動中不被察覺。作者提供可複製的多層次工作坊方法，並指出結果能否推廣至其他族群、情境與任務仍待研究。 |

**對「介面斷裂」主題的用途（推論）**：可作為「使用者與 AI 生成物之間的關係／期待落差」的理論參照，與「生成後棄置」現象在概念上相鄰，但兩者的因果關係需自行論證，原文並未談持續使用率。
